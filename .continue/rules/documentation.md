# Project Architecture

This is the start of a new system for FoundryVTT based on the boilerplate system. This project will change the boilerplate system to create my own system. It provides a basic structure and tools to get you started with your project.

The project is built in html, css, js and handlebar. The project  is structured as follows:

'system.json': The main system file that defines the system's structure and features.
'templates': contains the templates for creating actors and items.
'assets': contains the assets for images, sounds, etc.
'module': contains the main code for the system.
'lang': contains language files for different languages.
'css': contains CSS stylesheets.

You can read, write, and modify any files listed and contained in these folders. You can also add new files or directories as needed.
